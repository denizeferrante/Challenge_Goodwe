# Nunito

Fonte do app ChargeGrid (`design-system/tokens.json`), usada também na apresentação
`docs/ChargeGrid-Sprint4.pptx`. Instale os cinco arquivos `.ttf` desta pasta antes de abrir
a apresentação; sem eles, o PowerPoint troca a fonte e a diagramação muda.

Gerados a partir de `app/assets/fonts/nunito-latin.woff2` (Nunito, SIL Open Font License 1.1).
